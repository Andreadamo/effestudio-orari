# Orari Trainer Effestudio

Dashboard orari trainer (stile Google Calendar) pubblicata su GitHub Pages.
I dati restano nel Google Sheet "Orari Trainer Effestudio" e nel calendario "Disponibilità Trainer e assenze":
la web app Apps Script "Dashboard orari trainer+" risponde in JSON (doPost in `Api.gs`). L'indirizzo è in `config.js`.
